3.4.3 Mô tả chi tiết 25 bảng dữ liệu Mongoose Schemas

Hướng dẫn Copy vào Microsoft Word cực kỳ nhanh và chuẩn:
1. Mở file HTML này bằng trình duyệt web bất kỳ (Chrome, Edge, Cốc Cốc...).
2. Dùng chuột bôi đen bảng (hoặc nhấn Ctrl + A để chọn tất cả các bảng).
3. Nhấn Ctrl + C để Copy.
4. Mở tài liệu Word của bạn, đặt con trỏ chuột tại vị trí muốn dán và nhấn Ctrl + V.
5. Tất cả sẽ hiển thị dưới dạng bảng Word cực kỳ đẹp mắt, căn chỉnh chuẩn xác cột và viền, có thể chỉnh sửa trực tiếp được ngay!

1. Bảng `accounts` (Tài khoản người dùng)

STT Thuộc tính Kiểu dữ liệu Ràng buộc Diễn giải
1 _id ObjectId PK, Auto Khóa chính.
2 username String Required, Unique, Trim Tên đăng nhập.
3 password_hash String Default: "" Mật khẩu đã mã hóa.
4 email String Required, Unique, Lowercase, Trim Email.
5 full_name String - Họ tên đầy đủ.
6 phone String - Số điện thoại.
7 address String - Địa chỉ.
8 date_of_birth String - Ngày sinh.
9 avatar_link String - Link ảnh đại diện.
10 is_active Boolean Default: true Trạng thái hoạt động.
11 role String Required, Enum: ["customer", "staff", "admin"] Quyền truy cập.
12 isDelete Boolean Default: false Cờ xóa mềm.
